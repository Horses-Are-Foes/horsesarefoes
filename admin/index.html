Use this editor to write and publish reports. Nothing here touches the command line.

How it works

  1. Click Sign in (top right) and log in with your GitHub account — it's read-only (sign-in only, no command line).
  2. Choose Create New at the top, then Reports to start a new report.
  3. Fill in the fields: Title, Author, Published, Cover image, Warning banner, Subtitle, Keywords, Body.
  4. For Cover image or body images: click the upload/select icon under the field, pick an image, then click it to paste its path (it goes to the assets/ folder).
  5. Click Save draft to preview, or Publish to make it live. Each save shows a message like "Committed to main by [your GitHub name]" — that's your edit going to the site.
FieldWhat it does
TitleThe headline + the URL slug.
AuthorWho the report is by.
PublishedWhen it went live (e.g. November 3, 2026).
Cover imageBig cover art. Leave blank to auto-pick the first image in the story.
Warning bannerThe scrolling top banner. Leave blank to auto-fill from the title.
SubtitleThe short intro near the top of the report.
KeywordsComma-separated, shown in the page header for search.
BodyThe story itself (bold, italics, links, lists, images).
Tip for the owner. If you'd prefer friends to sign in with a simple email invite instead of a GitHub account, switch to the git-gateway backend (the commented block at the top of admin/config.yaml — enable Netlify Identity's Git Gateway and one line change is all it takes).
